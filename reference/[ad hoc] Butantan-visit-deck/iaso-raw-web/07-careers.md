# 职业发展

## 一、学习发展

### 发展理念

![学习发展](https://cn.iasobio.com/uploads/2021-07/10/_1625882013_9747.jpg)

作为一家快速发展的创新生物药公司，驯鹿生物倡导**"终身学习"**理念，将员工发展视为企业发展的动力。公司已逐步建立上接战略、下接绩效的培训体系，为员工提供多重形式的培训与提升机会。在鼓励员工持续学习进步的同时，也为具备各领域专业知识的人才提供发展机会，赋能公司整体项目的执行与运营效率的提升。

### 双通道职业发展
公司为员工职业发展建立了**"管理通道"**和**"专业通道"**双通道：
- 致力于改善人才发展现状
- 为专业人才提供更长远、更清晰的发展路径
- 实现人才的纵向、横向、螺旋型的复合型发展模式

## 五、为什么选择驯鹿

1. **行业前景**: 处于创新生物制药行业前沿，细胞治疗领域领军企业
2. **发展空间**: 快速发展的公司提供广阔的职业发展空间
3. **学习成长**: 完善的培训体系和双通道职业发展路径
4. **工作环境**: 开放、多元化、包容的企业文化
5. **社会价值**: 为患者带来治愈希望，具有深远的社会意义
