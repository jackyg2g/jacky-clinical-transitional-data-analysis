# 产品管线

## 一、产品管线概述

驯鹿生物秉持前瞻性的视野，采用去风险化的策略，构建了多元、全面且均衡的产品管线。

**管线统计**:
- 已上市产品: 1款 (福可苏®)
- 在研产品: 9款
  - 3款自体CAR-T细胞疗法
  - 5款体内(in vivo)CAR-T细胞疗法
  - 1款抗体候选药物

---

## 二、核心产品

### 福可苏® (伊基奥仑赛注射液 / Eque-cel)

**产品类型**: BCMA靶向CAR-T细胞治疗产品

**已获批适应症**:
- 复发/难治性多发性骨髓瘤(r/r MM) - 中国NMPA批准(2023年6月)
- 复发/难治性多发性骨髓瘤(r/r MM) - 中国香港批准(2025年11月)
- 复发/难治性多发性骨髓瘤(r/r MM) - 中国澳门批准(2025年3月)

**在研适应症**:
- 2-3线多发性骨髓瘤 (NMPA IND批准)
- 重症肌无力(MG) - NMPA及FDA IND批准
- 多发性硬化症(MS) - FDA IND批准
- 系统性红斑狼疮(SLE)/狼疮性肾炎(LN) - FDA IND批准

**产品特点**:
- 全人源BCMA靶向CAR-T
- 已获FDA孤儿药资格认定(韩国、沙特阿拉伯)
- 已获日本CTN批准

## 五、核心技术平台支撑

产品管线依托以下五大技术平台:

1. **全人源抗体发现平台**
   - 基于超过2,400亿个抗体的全人源抗体库
   - 全人源单域抗体库支持双/多特异性产品开发

2. **高通量CAR-T疗法筛选与优化平台**
   - 整合单细胞分析和下一代测序技术
   - 快速筛选最有效CAR-T候选分子

3. **体内CAR-T平台**
   - 基因工程改造病毒载体
   - T细胞特异性启动子驱动CAR表达

4. **先进制造及CMC平台**
   - 全流程制造与质量体系
   - 支持从早期开发到商业化生产

5. **临床开发与临床转化研究平台**
   - 与顶尖医院建立联合实验室
   - 高效衔接临床前研究与临床应用
