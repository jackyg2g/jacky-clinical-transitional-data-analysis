## Context

CT103AC004 中心实验室检测结果数据为单一 Excel 文件（109,237 行 × 18 列），包含 28 个中心、54 个访视周期、28 个检测项目的检测记录。项目使用 Python 脚本进行数据处理和可视化，最终输出 Markdown 格式报告。

## Goals / Non-Goals

### Goals

- 建立可复用的数据预处理流程（Excel → 结构化分析）
- 生成覆盖数据质量和临床趋势的综合报告
- 图表清晰可读，适合打印和屏幕查看

### Non-Goals

- 不构建交互式仪表板或 Web 应用
- 不实现自动化定期更新（一次性分析）
- 不做统计建模或推断性分析

## Decisions

### 1. 数据处理工具选择

**Decision**: 使用 Python + pandas + openpyxl 进行数据处理，matplotlib + seaborn 生成图表

**Rationale**: pandas 适合处理大型表格数据，matplotlib/seaborn 生成的静态图表适合报告嵌入

**Alternatives Considered**:
- R: 统计分析能力强，但项目环境以 Python 为主，减少依赖
- Excel 直接分析: 数据量较大（10 万+行），Excel 操作效率低且不可复现

### 2. 报告结构设计

**Decision**: 报告分为四大章节：数据概览 → 数据质量评估 → 检测趋势分析 → 总结

**Rationale**: 先建立数据全貌，再深入质量和趋势，符合分析报告的逻辑顺序

### 3. 图表设计原则

**Decision**:
- 使用中文标签和标题
- 配色使用 seaborn 默认调色板，保持专业感
- 每张图表生成 PNG 格式，分辨率 150 DPI
- 每张图表配套 `.desc.md` 描述文件

**Rationale**: 中文报告需中文图表标注；PNG 格式兼容 Markdown 嵌入；描述文件满足项目规范

### 4. 访视周期排序

**Decision**: 按临床方案时间线排序访视周期（筛选期 → 桥接治疗 → 清淋前 → W8 → W12 → ... → 长期随访），非字母序

**Rationale**: 字母序会导致 W8 排在 W12 之后，不符合时间逻辑

## Data Model

### 源数据结构

```
Excel Sheet: 项目管理导出
├── 方案编号 (str) - 固定值 CT103AC004
├── 中心编号 (int) - 1-28
├── 观合样本编号 (str) - 样本唯一标识
├── 受试者筛选号 (int) - 患者标识
├── 访视周期 (str) - 54 个时间点
├── 样本类型 (str) - 6 种样本类型
├── 采集时间 (str) - 样本采集日期
├── 检测项目 (str) - 28 个检测大类
├── 检测分项 (str) - 78 个检测子项
├── 结果 (str) - 混合数值和文本
├── 单位 (str) - 检测单位
├── 检验备注 (str) - 实验室备注
├── 异常样本备注 (str) - 溶血/脂血等
├── 申请单备注 (str) - 申请单异常
├── 反审时间 (str) - 修正时间戳
├── 反审备注 (str) - 修正说明
├── 检测时间 (str) - 检测执行日期
└── 报告时间 (str) - 报告发布日期
```

### 分析中间数据

- 数值型结果: 从 "结果" 列提取可转换为 float 的值
- 定性结果: 免疫固定电泳等非数值结果保持文本
- 时间字段: 统一转换为 datetime 格式

## Architecture Patterns

- **脚本式分析流水线**: 每个任务对应一个独立 Python 脚本，放置于 `temp/` 目录
- **数据-图表-报告分离**: 数据处理产出中间结果 → 图表脚本读取中间结果生成图表 → 报告脚本整合文本和图表引用
- **图表描述文件**: 每个 `generated/*.png` 配套 `generated/*.png.desc.md`，仅描述内容不含分析

## Risks / Trade-offs

### Risk: 结果列数据类型混合

**Risk**: "结果" 列包含数值（如 "12.5"）和文本（如 "IgG, lambda 型"），解析时可能丢失或误分类

**Mitigation**:
- 按检测项目分组处理，已知定量项目强制数值解析
- 定性项目（IFE 等）保持文本分类统计
- 无法解析的值标记并在报告中说明

### Trade-off: 图表数量与报告篇幅

**Decision**: 控制核心图表在 8-12 张，聚焦关键指标

**Impact**: 部分次要指标仅以表格形式展示，不单独出图

## Open Questions

1. **样本编号与受试者的映射关系**
   - 一个受试者在同一访视可能有多个样本（不同样本类型）
   - 分析时按受试者+访视+检测分项聚合，取唯一值

2. **Daratumumab 药物干扰去除检测的处理**
   - 部分检测项目为 Daratumumab 干扰去除后的结果
   - 与常规结果并行展示，注明区别
